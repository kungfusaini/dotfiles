# Configuration architecture

This repo separates configuration by ownership, not by device category alone.

## Host / system configuration

Path: `hosts/<host>/`

Use this for machine-wide NixOS state: boot, kernel, networking, users, hardware enablement, udev rules, privileged services, and policies that should work even when no graphical user is logged in.

For this laptop, the host is `kirax1`:

```text
hosts/kirax1/
```

Examples:

- `modules/hardware/input.nix` — `keyd`, Caps/Escape swap, Copilot key normalization
- `modules/hardware/power/` — Lenovo platform profile and CPU EPP policy
- `modules/hardware/peripherals.nix` — Bluetooth, printing, GVFS/udisks, fingerprint reader

Rule of thumb: if it writes `/sys`, configures a system service, needs root, or affects all users, it belongs in host/system config.

## Home / user configuration

Path: `home/`

Use this for Sumeet's user session: dotfiles, Hyprland bindings, Waybar/Mako UI, terminal/editor config, user services, and scripts that depend on `$HOME`, `$XDG_RUNTIME_DIR`, the graphical session, or the user's PipeWire state.

Examples:

- `home/modules/hypr.nix` — Hyprland config and keybindings
- `home/modules/waybar.nix` — Waybar config and user-side status refreshers
- `home/modules/microphone.nix` — user microphone policy and generated mic scripts
- `home/modules/power-status.nix` — generated user-side power-profile status script
- `home/modules/voxtype.nix` — user dictation config

Rule of thumb: if it is a personal workflow or desktop UI behavior, it belongs in Home Manager.

## Mixed cases

Some features cross layers. Split them by what each layer owns.

### Microphone

- System audio stack / Bluetooth audio capability: host/system
- Pressing `XF86AudioMicMute` in Hyprland: home/user
- Waybar microphone status: home/user, generated by `home/modules/microphone.nix`
- User default PipeWire source switching: home/user

### Power profile

- Lenovo platform profile and Intel EPP sync: host/system
- AC power forcing/restoring performance profile: host/system
- Waybar icon showing the current profile: home/user UI, generated by `home/modules/power-status.nix`

## Naming

- `hosts/<name>` is an actual machine, not generic NixOS config.
- The current laptop host is `kirax1`.
- Generic reusable NixOS modules can later live under `modules/nixos/` if multiple hosts share them.
- Generic reusable Home Manager modules can later live under `modules/home/` or `home/modules/`.
