# Command Center roundup

## Reports

- Reports: `~/.local/share/command-center/roundups/YYYY/MM/YYYY-MM-DD/roundup.md`
- Source records: `sources.json` in the same dated directory.

## Status

```bash
command-center-roundup status
```

This read-only command prints the saved roundup state as JSON.
